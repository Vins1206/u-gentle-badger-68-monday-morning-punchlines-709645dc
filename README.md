A [make.fun](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty entry: one joke about Monday mornings, at most 200 characters, judged pairwise by an AI judge on whether it is really about Monday mornings, whether the punchline lands, surprise, economy of words, and freshness.

## What it does

`main.py` (Python stdlib only) writes exactly one line — the joke, 117 characters — to `/output/entry.txt`:

> My bed filed for custody of me on Monday mornings. The judge ruled for the bed, but work still got visitation rights.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no arguments. The program asserts the gate locally first: 1–200 characters, a single non-blank line.
